# Demo Project – Hibernate

## 📌 Project Overview
This project demonstrates the integration of Java, Hibernate ORM, and MySQL to perform database operations. It uses Maven to manage project dependencies and simplify project configuration.

## 🛠️ Technologies Used
- **Java** – Application development
- **Hibernate ORM 5.6.15.Final** – Object-relational mapping
- **MySQL** – Database management
- **MySQL Connector/J 8.0.33** – Database connectivity
- **Maven** – Dependency management

## ✨ Features
- Hibernate configuration and database connectivity
- Java application integration with MySQL
- Object-relational mapping using Hibernate
- Database operations, depending on the implemented Java classes

## ⚙️ Project Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/raj14kr/Demo_Project_Practice_Hibernate.git
   ```
2. Open the project in Eclipse or another Java IDE.
3. Ensure Java and Maven are configured.
4. Configure your MySQL database credentials in the Hibernate configuration file.
5. Update the database name and connection settings as required.
6. Run the Java application.

## 🎯 Objective
To learn and practice Hibernate ORM, Java database programming, Maven dependency management, and MySQL integration.
